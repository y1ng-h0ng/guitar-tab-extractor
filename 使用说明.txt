吉他谱视频提取工具 · 使用说明

本工具用于从带有六线谱画面的吉他教学视频中提取、拼接并整理谱面，最终生成适合查看和打印的 A4 PDF。

一、安装与启动

1. 下载项目并完整解压到一个单独文件夹，保留所有子文件夹和文件。
2. 安装 Python 3.10 或更高版本，建议使用 Python 3.12（64 位），并确保安装 Tcl/Tk 和 pip。
3. Windows 用户首次使用时双击 install_windows.bat 安装依赖。首次安装需要联网。
4. 安装完成后双击 launch_windows.bat 启动图形界面。

如果已经配置好 Python 环境，也可以在项目目录中运行：

python -m pip install -r requirements.txt
python gui.py

二、基本使用

1. 将一个视频拖入窗口，点击“选择视频”，或在“视频 / 分享链接”中粘贴视频链接（也支持含单个链接的分享文本）。
2. 直接点击“一键生成”即可，链接会自动解析并获取视频；本地视频的 PDF 默认保存在视频旁边，链接视频保存在项目的 output 文件夹，也可修改保存位置。
3. “每行小节”默认“自动”，根据小节宽度和连线自动安排，并让所有行长度一致；需要自定义时选择或输入 1–8，清空后恢复自动。采样频率和 DPI 也可按需调整。
4. 如果希望检查或手动调整谱面区域，可先点击“预览 / 框选谱面”。
5. “保存过程截图”和“生成报告文件”默认都不勾选；只有需要调试或保留详细处理记录时再开启。
6. 修改设置后，点击“一键生成”。更新旧版本后，启动脚本会自动补装缺少的拖放和链接下载依赖。
7. 处理完成后可以直接打开生成的 PDF；如果程序提示存在待核对内容，可点击“查看检查结果”。

链接输入说明：支持 HTTP(S) 视频直链和 yt-dlp 能解析的可访问视频页面。可点击“解析链接 / 分 P / 清晰度”，查看标题、时长、分辨率和封面，选择分 P 与清晰度；不设置也可以直接一键生成。列表最多显示前 200 个分 P。需要登录、付费、DRM 或受地区限制的视频可能无法获取，直播不支持。解析错误会区分失效链接、登录或权限要求、网络、清晰度和平台问题。
“处理时间”支持秒数或 时:分:秒，例如 22.5 至 1:20；留空处理整段。本地视频也可以限定时间。链接仍会获取所选分 P 的视频流，再只分析指定范围。
下载与处理进度默认保存在项目内 .tabextract-cache，取消、退出后仍可恢复。视频不上传到第三方解析站点。预览链接先获取视频，随后生成时复用下载；可随时取消。
链接解析失败时可更新解析器：在项目目录运行 .venv\Scripts\python.exe -m pip install --upgrade yt-dlp，或改用本地视频。

断点续做和重新排版：重新打开软件后，在“缓存管理”中载入任务，点击“一键生成”继续；也可重新输入相同视频。定位、扫描进度、已完成的提取片段和拼接结果自动复用，未完成步骤可能需补做。只改每行小节数、DPI 或输出位置时不会重新分析视频；已成功保存的局部修正也会复用。改变源视频、采样频率、颜色、框选或处理时间则使用新缓存。

缓存管理：显示大小、载入任务、清理过期缓存或一键清理全部。启动处理时自动清理 7 天未使用的项；超过 2 GiB 时优先清理较旧项，正在使用的任务会跳过。清理仅影响下载副本和处理缓存，保留原视频、PDF、报告和过程截图。缓存中的局部修正会随清理丢失，不能代替永久备份。命令行可用 --no-cache 禁用，或 --cache-dir 指定缓存位置。

三、谱面区域选择

程序会尝试自动定位视频中的六线谱区域。

如果自动定位不准确，可以使用“预览 / 框选谱面”手动选择区域。框选时应尽量完整包含六条谱线、数字、音符、H/P 等技巧标记、推弦箭头、文字、连音线、符干和符梁。

对于白色谱字叠在暗色画面上的视频，通常可使用“自动识别”，必要时选择“白字 / 暗底”。
对于白纸黑字谱面，必要时选择“黑字 / 白底”。

四、常用参数

每行小节：默认“自动”或留空，根据小节宽度安排每行 1–8 个小节，尽量保持跨小节连线在同一行。偏短的行优先多放一个完整小节后适度压缩，减少长小节被继续拉宽。也可以填写 1–8 自定义目标数量；短行在不会拆开连线、不会使下一行过短时，也可多放一个小节。两种模式均统一行宽，包括最后一行。过宽行先收紧安全空白，空白不足时整行横向缩放，压缩最多 15%；短行仍可补充空白以对齐。

DPI：设置 PDF 中谱面图像的最低输出分辨率。导出会保留提取图的原有精度，避免缩小时丢失细小标记。提高 DPI 不会恢复原视频中已经缺失或模糊的细节。

细节增强：音符数字、和弦、附点、连线和符干均按多帧一致性保留，容忍短暂的背景干扰或遮挡。H、P、滑音等清楚的小标记会做局部锐化；较淡的符号保留原有对比度，避免被进一步削弱。原视频中本来就没有的笔画不会自动补写。

外围杂线：对照多个已确认对齐的滚动画面，清理远离乐谱笔画、缺少支持的独立碎线。按整块碎片判断并移除，保护靠近谱面的附点、连音线和完整符干；证据不足或与乐谱重合的杂线仍会保留。

淡谱线：当六条谱线半透明、对比度低时，额外检查覆盖范围更宽的六条等距淡线，减少开头漏识别和整页被跳过，并按真实谱线间距保护较粗的符梁。仍只保留画面中有证据的笔画，不补画缺失的线段。

采样频率：控制程序分析视频画面的频率。更高的采样频率通常会增加处理时间。

保存过程截图：默认关闭。开启后会保存谱面区域、清洗结果、分行图和拼接长图等中间图像，主要用于排查提取效果。

生成报告文件：默认关闭。开启后会额外生成 .report.json 文件，记录页面、接缝、小节边界、排版和待核对项等详细处理信息。即使不生成报告文件，本次运行的检查结果仍可在 GUI 中查看。

五、输出文件

视频名_吉他谱.pdf
默认生成的 A4 吉他谱 PDF。谱面的最后一个小节会在输出阶段补上标准终止线，即一条细线和一条粗线。

视频名_吉他谱.report.json
仅在勾选“生成报告文件”时生成，用于保存详细处理信息。

debug_视频名/
仅在勾选“保存过程截图”时生成，用于保存中间处理图像。

因此在默认设置下，输出位置只生成 PDF，不额外生成报告文件或 debug 文件夹；处理缓存单独保存在项目内 .tabextract-cache。

如果同名 PDF 已存在，只有在新文件成功生成后才会替换。处理失败或取消时不会留下被截断的半成品 PDF。

六、适用范围

本工具更适合谱面位置相对固定、画面缩放基本稳定、单行六线谱横向翻页，并且相邻页面之间存在一定重叠的视频。

对于持续平滑滚动、明显倾斜拍摄、频繁缩放、谱面被大面积遮挡或复杂彩色谱面，自动处理效果可能下降。

图像处理无法恢复视频画面之外、严重模糊或被遮挡的内容。非常细小的技巧符号也会受到原视频清晰度限制。
